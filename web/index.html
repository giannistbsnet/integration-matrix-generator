Integration Matrix Generator

Generate an Excel integration matrix from a CSV or JSON component list

Components

Format

CSV

partner,task,component
ACME,T1.1,Order Service
NOVA,T2.1,Analytics Engine

JSON

[
  {
    "partner": "ACME",
    "task": "T1.1",
    "component": "Order Service"
  }
]

component is required.
partner and task are optional.

Matrix behavior

Fill the lower triangle. The upper triangle mirrors automatically:

  • ↗ mirrors as ↙
  • ↙ mirrors as ↗
  • ↔ mirrors unchanged
  • Interface copies counterpart

Direction options

↔   ↗   ↙

Interface options

  • REST API
  • GraphQL, gRPC
  • Kafka, MQTT
  • WebSocket
  • SPARQL endpoint
  • NGSI-LD
  • Eclipse Dataspace Connector (EDC)
  • AAS / Eclipse BaSyx
